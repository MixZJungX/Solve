# Lemon shop Solve | Helper

ระบบส่งงานแก้ Captcha Roblox อัตโนมัติเชื่อมต่อกับ HIGHSPEC Direct API พร้อมระบบจัดการฐานข้อมูลบัญชีและแยกสิทธิ์การใช้งานระหว่างหน้าลูกค้าและหลังบ้านแอดมิน

## ฟีเจอร์หลัก
- **หน้าลูกค้า (`/home`):** ลูกค้าใส่เฉพาะชื่อตัวละคร (Username) เพื่อแก้แคปช่า ไม่ต้องใช้รหัสผ่าน
- **หลังบ้านแอดมิน (`/admin`):**
  - กำหนดโหมดคิวงาน (คิวปกติ หรือ เร่งด่วน x2)
  - จัดการฐานข้อมูลบัญชี (Bulk Import `user:pass:cookie`)
  - ตรวจสอบยอดเงินร้านค้าแบบ Real-time
  - ดูประวัติงานทั้งหมด

## วิธีการรันบนเครื่อง Local
ดับเบิ้ลคลิกไฟล์ `start.bat` หรือรัน:
```bash
php -c php.ini -S 127.0.0.1:8000 router.php
```
